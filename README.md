#### 🎵 The iPod Revival Ecosystem
* [**ClickWheel**](https://github.com/BowerHarry/docs-hub/blob/main/click-wheel/README.md) – macOS app with a retro iTunes-inspired interface for syncing music to legacy iPods, wired or wirelessly.
* [**libsyncsupport**](https://github.com/BowerHarry/docs-hub/blob/main/libsyncsupport/README.md) – Low-level Swift sync engine that writes Apple's iTunesDB, verified on real hardware.
* [**TheBridge**](https://github.com/BowerHarry/docs-hub/blob/main/the-bridge/README.md) – Ultra-miniature ESP32 accessory on a custom four-layer PCB, plugging into an iPod's 30-pin port for wireless syncing.
* [**libpodbridgesupport**](https://github.com/BowerHarry/docs-hub/blob/main/libpodbridgesupport/README.md) – Swift package for TheBridge discovery and API access.
